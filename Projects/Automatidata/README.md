# Automatidata – NYC Taxi Fare Prediction

## Project Overview

This project is part of the **Google Advanced Data Analytics Professional Certificate** and focuses on applying data analytics and machine learning techniques to a real-world business scenario.

Automatidata is a fictional data consulting company working with data from the New York City taxi industry. The objective is to analyze taxi trip data, identify relevant patterns, and develop predictive models to support data-driven business decisions.

## Business Problem

The project focuses on understanding the factors that influence taxi fares and exploring how data science techniques can help predict trip costs.

The main analytical objective is to identify meaningful relationships within taxi trip data and evaluate the potential of predictive modeling to estimate taxi fares.

## Dataset

The analysis uses New York City taxi trip data, including information about individual trips and their associated characteristics.

The dataset is explored to identify patterns, understand variable relationships, detect potential data quality issues, and prepare the information for statistical analysis and predictive modeling.

## Methodology

The project follows a structured data analytics workflow:

1. **Data Inspection:** Understanding the dataset structure, variables, and data quality.
2. **Data Cleaning & Preparation:** Identifying missing values, outliers, and inconsistencies.
3. **Exploratory Data Analysis (EDA):** Investigating distributions, patterns, correlations, and relationships between variables.
4. **Statistical Analysis:** Applying statistical techniques to investigate relevant data patterns and relationships.
5. **Feature Engineering:** Preparing relevant variables for predictive modeling.
6. **Predictive Modeling:** Developing a regression model to estimate taxi fares.
7. **Model Evaluation:** Assessing model performance and interpreting the results.
