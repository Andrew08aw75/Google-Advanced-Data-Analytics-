# Applied Data Analytics Projects

Three projects focused on real-world data analytics challenges, covering exploratory data analysis, statistical methods, and machine learning applications.

## Projects

### 1. Automatidata – NYC Taxi Fare Prediction
Analysis of New York City taxi trip data to identify factors influencing fare amounts and develop predictive models using regression and machine learning techniques.

### 2. Waze – User Churn Prediction
Analysis of user activity patterns to identify factors associated with user churn and develop machine learning models to predict users at risk of leaving the platform.

### 3. TikTok – Video Classification
Analysis of TikTok video data to identify patterns in user engagement and develop classification models to distinguish claims from opinions, supporting content moderation processes.

## Analytical Workflow

Projects follow an EDA-driven structure, progressing from data exploration and statistical analysis to regression and machine learning.

- Exploratory Data Analysis (EDA)
- Data Cleaning and Preparation
- Statistical Analysis
- Regression Analysis
- Machine Learning & Predictive Modeling
