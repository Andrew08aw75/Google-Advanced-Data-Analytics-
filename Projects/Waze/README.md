# Waze – User Churn Prediction

## Project Overview

This project is part of the **Google Advanced Data Analytics Professional Certificate** and focuses on applying data analytics, statistical methods, and machine learning techniques to a user retention business problem.

Waze is a navigation application that relies on user engagement and activity to provide navigation services and improve the overall user experience.

The project explores user behavior and engagement patterns to identify factors associated with user churn and develop predictive models that can support data-driven retention strategies.

## Business Problem

Waze aims to better understand user behavior and identify users who may be at risk of stopping their use of the application.

The main analytical objective is to investigate patterns associated with user engagement and develop a predictive approach to identify potential user churn.

These insights could help the business understand user retention challenges, prioritize engagement strategies, and support data-driven decision-making.

## Dataset

The project uses user activity and engagement data associated with Waze.

The dataset is explored to understand user characteristics, identify behavioral patterns, investigate relationships between variables, and prepare the information for statistical analysis and predictive modeling.

## Methodology

The project follows a structured data analytics and machine learning workflow:

1. **Data Inspection:** Understanding the dataset structure, variables, and data quality.
2. **Data Cleaning & Preparation:** Identifying missing values, inconsistencies, and potential outliers.
3. **Exploratory Data Analysis (EDA):** Investigating user behavior, engagement patterns, and relationships between variables.
4. **Statistical Analysis:** Applying statistical techniques to identify relevant patterns and relationships.
5. **Feature Engineering:** Preparing relevant variables for predictive modeling.
6. **Predictive Modeling:** Developing classification models to identify users who may be at risk of churning.
7. **Model Evaluation:** Assessing model performance using appropriate classification metrics.
