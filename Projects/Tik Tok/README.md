# TikTok – Claims Classification & Predictive Modeling

## Project Overview

This project is part of the **Google Advanced Data Analytics Professional Certificate** and focuses on applying data analytics, statistical methods, and machine learning techniques to a content moderation business case.

The project explores TikTok video data to identify patterns associated with user-generated content and develop predictive models that can help distinguish between videos containing claims and opinions.

## Business Problem

TikTok aims to improve its content moderation process by identifying videos that may require further review.

The analytical objective is to investigate the characteristics of videos containing claims or opinions and explore how machine learning models can support the identification and classification of potentially problematic content.

Automating part of this process could help prioritize content for human review and improve moderation efficiency.

## Dataset

The project uses a dataset containing information about TikTok videos, including metadata and engagement-related variables.

The data is explored to understand video characteristics, identify relevant patterns, investigate relationships between variables, and prepare the dataset for predictive modeling.

## Methodology

The project follows a structured data analytics and machine learning workflow:

1. **Data Inspection:** Understanding the dataset structure, variables, and data quality.
2. **Data Cleaning & Preparation:** Identifying missing values, inconsistencies, and potential outliers.
3. **Exploratory Data Analysis (EDA):** Exploring distributions, patterns, and relationships between video characteristics and content categories.
4. **Statistical Analysis:** Investigating relevant patterns and relationships using statistical techniques.
5. **Feature Engineering:** Preparing relevant features for classification.
6. **Predictive Modeling:** Developing machine learning classification models to distinguish between claims and opinions.
7. **Model Evaluation:** Assessing model performance using appropriate classification metrics.
