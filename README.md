# Google Advanced Data Analytics – Portfolio

## Overview

This repository contains a collection of data analytics exercises, practical assignments, and case studies developed throughout the **Google Advanced Data Analytics Professional Certificate**.

The projects demonstrate the application of analytical techniques and data science methodologies, following a structured approach to data exploration, statistical analysis, and predictive modeling.

The repository includes hands-on experience with Python, statistical methods, data visualization, regression, and machine learning.

## Featured Projects

The `Projects` directory contains three practical case studies:

| Project | Description |
|---|---|
| **Automatidata** | Data analysis and exploration applied to a business case. |
| **Waze** | Analytical case study involving data exploration and predictive modeling. |
| **TikTok** | Data analysis and machine learning applied to a classification problem. |

Each project includes Jupyter Notebooks with the corresponding analysis, code, and results.

## Analytical Workflow

The exercises and case studies cover different stages of the data analytics lifecycle:

1. Data understanding and preparation.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis (EDA).
4. Statistical analysis and hypothesis testing.
5. Data visualization and interpretation.
6. Predictive modeling and machine learning.
7. Model evaluation and analytical insights.

## Purpose

This repository serves as a practical portfolio showcasing the technical skills, analytical methods, and problem-solving approaches developed throughout the Google Advanced Data Analytics Professional Certificate.
